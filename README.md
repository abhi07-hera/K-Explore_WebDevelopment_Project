# NEXUS // Cyber Event Management Website

A futuristic cyber-themed event management website built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Cyber/futuristic visual system
- Responsive desktop/tablet/mobile layout
- Event search and category filters
- Featured event spotlight
- Event detail modal
- Registration modal with JavaScript validation
- Registration saved in Local Storage
- Registration success toast
- Live countdown
- Dark/light mode
- Random event access
- Scroll reveal animations
- Animated ticker and terminal-style hero
- No framework required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub
```bash
git init
git add .
git commit -m "NEXUS cyber event website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/nexus-event-management.git
git push -u origin main
```

## Deploy
Upload the repository to GitHub and deploy it using GitHub Pages, Netlify, or Vercel.

## Customization
Edit the `events` array at the top of `script.js` to add/change events, images, dates, venues and categories.
